# DeDT Platform

**Blockchain-powered Digital Twins Platform to Foster Trust, Transparency, and Collaboration**

Open-source code of the DeDT research project. DeDT explores how Web 3.0 technologies (blockchain, NFTs and DAOs) can support digital twin projects through tamper-proof data sharing, IP protection, decentralized fundraising and auditable predictive analytics.

🌐 Project website: https://smhbamakan.github.io/DeDT/

## Research objectives

- **O1** Identify the crucial challenges of digital twin projects and evaluate how emerging Web 3.0 technologies can resolve them.
- **O2** Develop a tamper-proof, decentralized collaboration platform for digital twin data sharing and federated learning.
- **O3** Design an Intellectual Property-based NFT framework (IP-NFT) for digital twin provenance and decentralized fundraising.
- **O4** Provide a blockchain-based predictive analytics platform for trust, transparency and auditability in digital twin projects.
