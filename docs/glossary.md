# Glossary

| Term | Meaning |
|---|---|
| **Digital twin (DT)** | A virtual model of a physical asset kept in sync with it through data |
| **Twin team** | The organisations and people who build and operate a twin together |
| **Birth certificate** | The attributes that identify a twin at creation (asset, manufacturer, serial, specification), committed on chain |
| **IP-NFT** | ERC-721 token that certifies a twin, its specification hash and its version trail |
| **dNFT** | Dynamic NFT of WP1 that carries the twin's state across chains |
| **Merkle batch / hash chain** | Readings grouped into a Merkle tree; each batch hash includes the previous one |
| **KPI evidence** | Hash binding a KPI value to the data and model configuration it was computed from |
| **DTVF** | Digital-Twin-Verified Financing: staged funding released against KPI milestones (D3.2) |
| **Bond (κ)** | Deposit posted with a claim or challenge; the losing side forfeits it |
| **Quadratic matching** | Matching funds proportional to (Σ√contribution)² − Σ contribution |
| **IBE / DKG** | Identity-based encryption; the master key is shared by t-of-n key servers created by distributed key generation |
| **BLS aggregate signature** | One signature that proves several sensors signed the same batch |
